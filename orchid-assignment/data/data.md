# Data Folder

This folder stores the agriculture export workbook and the cleaned datasets used for the assignment.

Raw or original datasets should generally not be uploaded unless the assignment specifically requires them. For this project, the cleaned 2024 CSV outputs are treated as assignment deliverables and are saved in `data/processed/`.

## Folder Structure

```text
data/
|-- export_of_agriculture_products_data.xlsx
|-- processed/
|   |-- agriculture_export_values_2024_clean.csv
|   |-- agriculture_export_quantities_2024_clean.csv
|   `-- agriculture_exports_2024_infographic_ready.csv
`-- data.md
```

## Processed Outputs

- `agriculture_export_values_2024_clean.csv`: cleaned 2024 export value data with aggregate rows removed.
- `agriculture_export_quantities_2024_clean.csv`: cleaned 2024 export quantity data with aggregate rows removed.
- `agriculture_exports_2024_infographic_ready.csv`: joined value and quantity dataset for the redesigned static infographic.

The cleaned outputs are generated by `orchid-assignment-2024-eda.qmd`.
